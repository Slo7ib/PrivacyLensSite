Privacy Policy

Introduction

Privacy Lens is a browser extension designed to help users understand website privacy policies by analyzing them and presenting simplified summaries and visual indicators. We respect your privacy and are committed to transparency regarding how data is processed. This Privacy Policy explains what information is accessed, how it is used, and your choices when using the extension.

When Data Is Processed

Privacy Lens processes data only when you actively interact with the extension, such as clicking the "Scan" button. The extension does not run automatically in the background and does not monitor your browsing activity.

Information We Process

1. Page Content and URLs

When you trigger a scan:

  • The extension reads the URL of the currently active tab
  • It searches the page for a link to the website's privacy policy
  • If found, the text of that privacy policy page is extracted
  • This content is sent to our secure backend solely for the purpose of generating a summary and privacy indicators using AI

Note: We do not analyze other website content beyond the privacy policy.

2. Identifiable Data (Anonymous Installation ID)

A random, non-personally identifiable installation identifier (chrome.runtime.id) is sent to our backend to:

  • Facilitate the AI analysis service
  • Apply basic rate limiting
  • Prevent abuse of the service

This identifier:

  • Does not reveal your identity
  • Is not linked to personal information
  • Is not used for tracking or advertising

3. AI Processing

The extracted privacy policy text is processed by an AI model to:

  • Generate simplified summaries
  • Determine which privacy-related icons should be displayed (e.g. data collection, sharing, usage)

Data sent to the backend is processed transiently, only for the duration required to generate the analysis, and is not retained.

Local Storage

The extension stores:

  • Generated summaries
  • Scan status for previously analyzed websites

This data is stored locally on your device using chrome.storage. No analysis results are stored on our servers.

Information We Do NOT Collect

Privacy Lens does not:

  • Collect names, email addresses, or account information
  • Track browsing history
  • Collect passwords, form inputs, or authentication data
  • Collect precise location data
  • Build user profiles
  • Sell, rent, or share personal data for advertising or marketing purposes

Data Sharing

Privacy Lens does not sell or trade user data. Data may be processed by:

  • Our secure backend infrastructure
  • Third-party AI service providers used exclusively to generate summaries

These parties act solely as data processors and only for the functionality explicitly initiated by the user.

Permissions Justification

The extension requires the following permissions:

activeTab

Required to access the URL and content of the specific tab you are currently viewing when you open the extension. This allows the extension to locate and analyze the privacy policy without accessing your broader browsing activity.

scripting

Required to inject a content script into the active page in order to locate the "Privacy Policy" link within the page's DOM. This powers the core "Scan" functionality.

storage

Required to save generated privacy summaries and scan status locally on your device, so you don't need to re-scan the same website every time.

Backend API Access

Required to securely send the extracted privacy policy text to our backend for AI processing and summarization.

https://openrouter.ai/

Required to communicate with the Large Language Model provider used to generate privacy summaries and data collection indicators.

Compliance With Chrome Web Store Policies

Privacy Lens complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data accessed is used strictly to provide the extension's core functionality and for no other purpose.

User Control

  • The extension runs only when you choose to use it
  • No automatic or background analysis occurs
  • You may uninstall the extension at any time to stop all processing

Security

We take reasonable measures to protect processed data, including:

  • Secure backend communication
  • Keeping API credentials off the client side
  • Limiting backend access to required functionality only
